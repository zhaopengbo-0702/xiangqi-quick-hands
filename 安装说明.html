Pikafish NNUE · 对局、题库与棋盘分析

安装与更新 2.3.0

  1. Edge 地址栏输入 edge://extensions；Chrome 输入 chrome://extensions。
  2. 打开“开发人员模式”，点击“加载解压缩的扩展”。
  3. 选择本文件旁的 extension 文件夹，其中直接包含 manifest.json。已有插件时点击重新加载，确认版本为 2.3.0；后台会尝试在已打开的棋盘页恢复新面板。
  4. 可选运行 powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-pikafish.ps1 安装 Windows 本地加速组件。没有本地主机也可使用内置皮卡鱼 NNUE 浏览器引擎。
  5. 打开 在线对局 或 人机对弈，进入自己的棋局。
  6. 等待右下角显示“Pikafish · NNUE”和“引擎就绪”，点击“开始自动”或“走一步”。首次加载 NNUE 会预热数秒。

需要 Chrome / Edge 116 或更新版本。内置引擎可独立运行，无需 Python、Node、API Key 或 HTTP 服务。可选本地加速组件需要 Windows 64 位和 Python 3.9 或更新版本。

推荐参数

模式自适应
稳健度0.65
最长计算3.5 秒
普通局面搜索深度至少 6 层
单步总预算最多 5 秒，过期停止落子

候选接近、主变化不稳定、评分波动、重要吃子或应将时增加计算时间。候选明显领先且稳定时提前结束。控制台可查看重要性、预算、实际耗时和后续变化。

在线大厅等待进入自己的对局。观战棋盘禁用自动落子；限时对局会根据剩余时间缩短计算预算。新局需要重新开启自动行棋。

使用官方 Pikafish 的 Alpha-Beta 搜索与 NNUE 评估。限时搜索无法保证全局最优；重要性是时间分配估计。支持切换到后台或最小化后继续执行；电脑睡眠、页面冻结或关闭浏览器时无法持续运行。NNUE 网络有独立许可，未经授权不得商用。

题库与分析棋盘

支持普通题库、练习、挑战与竞速题目；完成、判错或切题后暂停，不读取答案树，不自动进入下一题。每日入口若进入同一题目页面，使用相同适配。在分析、复盘、棋谱和课程等页面，识别到有效棋盘后可点击“分析局面”，只显示引擎建议，不自动落子；编辑器不会自动摆棋。详细页面范围见 README。

面板大小与位置

拖动面板四边或四角时，文字、图标、按钮一起按比例缩放；也可使用面板内的 A− / A+ 每次调整 10%。默认正文 16px，辅助信息 14px。高度随实际内容收紧，不再保留旧版底部的大块空白；超出屏幕时正文可滚动。拖动标题栏空白处移动，双击恢复 100% 和默认位置；比例和位置自动保存。旧版固定高度会自动移除。

操作变化

默认开启“操作变化”，在选子前后加入短暂随机等待，并在棋子中心小范围内变化点击位置；可在面板关闭并记住选择。时间不足时压缩等待，暂停或局面变化后停止，不延长原落子时限。这不保证避开官方反作弊或避免封禁，合成输入仍可被识别。

后台执行

开启自动行棋后，可以切换标签页、让其他窗口覆盖浏览器或最小化，插件会继续读取棋盘和落子，不会抢回前台焦点。手动暂停、关闭页面或浏览器后停止。电脑睡眠、页面被浏览器冻结或丢弃时无法持续执行；恢复后拒绝过期落子。网页内弹窗遮住棋盘时仍会停止。

连接检查

2.1.3 修复读取到旧棋盘数据导致“网站未确认落子”的误停。确认阶段最多等待 1500 ms，始终受本步 5 秒截止时间约束，不重复点击落点。短暂不同步时显示“等待棋盘同步”，恢复后继续自动行棋，无需反复点击启动。持续 2 秒仍不同步或已点击落点但无法确认时暂停；手动暂停、切换对局和开始新局后不会自动恢复。

Extension context invalidated. 表示旧面板与已重载的扩展断开。新版会尝试自动恢复原页面上的新面板，棋局不刷新且保持暂停；没有恢复时点击浏览器工具栏的插件按钮。旧面板显示“插件已更新，请重新连接”时，点击其重新连接按钮会刷新棋盘。

旧版出现 Specified native messaging host not found. 时，重新加载扩展并确认版本 2.3.0，必要时刷新棋盘。新版可自动改用“NNUE 浏览器引擎”。网络完整性或 NNUE 验证失败时会停止并显示原因。

可选在完整 Windows 包目录运行 npm.cmd run verify，打开启动输出的网址，默认 http://127.0.0.1:8791/。未启动服务时该网址会拒绝连接；正常行棋不依赖此服务。本机检查通过不代表当前浏览器扩展已经连接。
