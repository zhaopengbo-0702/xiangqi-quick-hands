安装与更新 2.6.0

  1. 从 GitHub Releases 下载唯一的浏览器独立包 xiangqi-quick-hands-v2.6.0.zip 并解压，保留整个目录。
  2. Edge 地址栏输入 edge://extensions；Chrome 输入 chrome://extensions，打开“开发人员模式”，点击“加载解压缩的扩展”。
  3. 选择刚解压、直接包含 manifest.json 的目录；若使用仓库源码，则选择本文件旁的 extension 文件夹。已有插件时，用新版文件替换原目录再点击重新加载，确认版本为 2.6.0；后台会尝试在已打开的棋盘页恢复新面板。
  4. 打开 在线对局 或 人机对弈，进入自己的棋局。
  5. 等待右下角显示“Pikafish · NNUE”和“引擎就绪”，点击“开始自动”或“走一步”。首次加载 NNUE 会预热数秒。

只提供浏览器独立版，需要 Chrome / Edge 116 或更新版本。内置 WASM 引擎与 NNUE，无需 Python、Node、API Key、本地组件或 HTTP 服务。

运行中调整参数

“搜索模式”“最长计算”和自适应模式下的“决策偏好”在自动行棋、正在计算或等待对方时都可修改，无需暂停。拖动偏好滑条时百分比实时更新，松开后保存，刷新后恢复。本步保持开始时的设置，新选择从下一步生效，不取消或重启当前计算。固定时限模式隐藏偏好条，切回自适应后显示。2.5.1 修复了旧版运行中误锁偏好滑条的问题。

评估显示

2.6.0 的普通“评估”只显示 (-1, 1) 内的新分数，固定六位小数，零为 0.000000。转换关系为 新评估 = tanh(1.5 × 旧面板评分) = tanh(0.015 × cp)，其中 cp 是引擎的百分兵分。输入允许任意有限旧评分，1.5 是尺度系数，不是评分范围或截断值。零点导数为 1.5，均势附近的小变化更明显，大优势更快饱和接近 ±1。旧尺度仅用于本说明中的升级换算，面板不并列原值。

在线大厅等待进入自己的对局。观战棋盘禁用自动落子；限时对局会根据剩余时间缩短计算预算。新局需要重新开启自动行棋。

使用官方 Pikafish 的 Alpha-Beta 搜索与 NNUE 评估。限时搜索无法保证全局最优；重要性是时间分配估计。支持切换到后台或最小化后继续执行；电脑睡眠、页面冻结或关闭浏览器时无法持续运行。NNUE 网络有独立许可，未经授权不得商用。

题库与分析棋盘

支持普通题库、练习、挑战与竞速题目；完成、判错或切题后暂停，不读取答案树，不自动进入下一题。每日入口若进入同一题目页面，使用相同适配。在分析、复盘、棋谱和课程等页面，识别到有效棋盘后可点击“分析局面”，只显示引擎建议，不自动落子；编辑器不会自动摆棋。详细页面范围见 README。

面板大小与位置

拖动面板四边或四角时，文字、图标、按钮一起按比例缩放；也可使用面板内的 A− / A+ 每次调整 10%。默认正文 16px，辅助信息 14px。高度随实际内容收紧，不再保留旧版底部的大块空白；超出屏幕时正文可滚动。拖动标题栏空白处移动，双击恢复 100% 和默认位置；比例和位置自动保存。旧版固定高度会自动移除。

操作变化

默认开启“反侦查辅助（操作变化）”，在选子前后加入短暂随机等待，并在棋子中心小范围内变化点击位置；主面板内可随时开启或关闭并记住选择；运行中切换从下一步生效。时间不足时压缩等待，暂停或局面变化后停止，不延长原落子时限。这不保证避开官方反作弊或避免封禁，合成输入仍可被识别。

后台执行

开启自动行棋后，可以切换标签页、让其他窗口覆盖浏览器或最小化，插件会继续读取棋盘和落子，不会抢回前台焦点。手动暂停、关闭页面或浏览器后停止。电脑睡眠、页面被浏览器冻结或丢弃时无法持续执行；恢复后拒绝过期落子。网页内弹窗遮住棋盘时仍会停止。

防误触暂停

先点“暂停自动”或右上角暂停图标，只会出现确认条，运行仍继续；再点独立的“确认暂停”才停止。“继续运行”、Esc 或 8 秒未确认会取消请求。连续点原按钮不算确认。自动期间重连按钮禁用，防止误触中断。

短暂同步、读取超时、加载、断线或落子前遮挡会等待恢复，保持同一局自动运行。落点已发送但网站暂未反馈时只读等待，不重复点击。换局、回放、身份变化、题目判错、明确其他走法、终局和派发前时间不足等必要情况仍会停止并显示原因。

落子确认与连接检查

2.6.0 修复“网站未在时限内确认落子，已暂停”的迟反馈误停。落点发送前仍受原本步最多 5 秒的动作截止时间约束；发送后停止动作超时计时，转入独立只读确认，不再受旧版 1.5 秒确认上限或原动作 5 秒截止时间影响。等待期间保留自动和忙碌状态，不启动下一次搜索，不重复发送落点。

单次 650 ms 读取超时、短暂状态不同步或棋盘暂未加载时继续等待；当前局面或严格匹配的近期局面记录确认预期着法后，才恢复后续流程。一直无法确认时继续等待，可用两步确认暂停中止。换局、回放、身份变化、题目判错、明确其他走法或终局仍会停止；这不能保证所有网站错误都会自动恢复。手动确认暂停、切换对局和开始新局后不会自动开启行棋。

Extension context invalidated. 表示旧面板与已重载的扩展断开。新版会尝试自动恢复原页面上的新面板，棋局不刷新且保持暂停；没有恢复时点击浏览器工具栏的插件按钮。旧面板显示“插件已更新，请重新连接”时，点击其重新连接按钮会刷新棋盘。

旧版出现 Specified native messaging host not found. 时，重新加载扩展并确认版本 2.6.0，必要时刷新棋盘。新版可自动改用“NNUE 浏览器引擎”。网络完整性或 NNUE 验证失败时会停止并显示原因。
