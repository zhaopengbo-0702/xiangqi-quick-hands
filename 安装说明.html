安装与更新

  1. 从 GitHub Releases 下载 xiangqi-quick-hands-v2.7.3.zip 并解压。
  2. Edge 打开 edge://extensions，Chrome 打开 chrome://extensions，开启“开发人员模式”。
  3. 点击“加载解压缩的扩展”，选择直接包含 manifest.json 的目录。源码安装时选择 extension 文件夹，保留安装目录供浏览器加载。
  4. 更新旧版时，用新版文件替换原目录并点击“重新加载”。刷新棋盘，确认面板标题显示 v2.7.3。
  5. 进入自己的对局，等待“引擎就绪”，点击“开始自动”或“走一步”。首次预热需要数秒。

适用 Chrome / Edge 116 或更新版本。浏览器独立包内含 WASM 引擎、NNUE、对应源码和许可证。

运行中调整

“搜索模式”“最长计算”和自适应模式下的“决策偏好”可随时调整，新设置从下一步生效。滑条百分比实时更新，松开后保存，刷新后恢复。

本局评估走势

主面板平滑走势曲线随每次成功计算更新。横轴是评估局面的手数，每手表示一个单方步；纵轴固定为 −1 至 +1。参与对局时自动按自己控制的棋子计算，正值自己有利、负值对方有利，零线表示均势。记录点提示直接显示手数和评估值。

连线采用保形分段三次 Hermite / PCHIP 插值，一阶导数连续且段内保持在相邻样点范围内。平滑仅影响连线，实际评估点不变。

普通评分沿用现有六位局势指数；非零杀棋点标记在 ±1，参与对局时标注我方或对方杀棋，“杀棋 0”跳过图表记录。数字评估继续显示“杀棋 N”。同一手再次计算更新对应点，暂停、收起面板和重连引擎后保留本局记录。

启动后会真实计算本局初始局面，补齐第 0 手评估；开局采集只做分析，不落子，也不预设零分。执黑时同样先采集开局点，再记录正常行棋评估。采集失败不会暂停自动行棋，稍后重试。

切换对局、题目或识别人机重新开局后自动清零。中途进入可根据合法初始局面补采开局点，其他未计算过的历史手数不补造。

读懂面板

评估以六位小数显示，正值有利、负值不利，零附近为均势。分档依次为均势、稍优或稍劣、明显优势或劣势、大幅优势或劣势、接近胜势或败势。强制杀棋显示“杀棋 N”。

深度表示向后搜索的单方步数；重要性用于分配本步计算时间；预算是计划搜索时间，耗时包含读取、计算和落子确认。底部线路展示引擎预测的双方后续走法。

全部转换公式、PCHIP 插值函数、系数和复算示例已用 LaTeX 排版，见 评估转换与插值函数。

题库与分析

支持普通题库、练习、挑战与竞速题目；每日残局进入题库页面时使用同一适配。完成、判错或切题后暂停，新题点击“开始自动”。分析、复盘、棋谱、课程和编辑器使用“分析局面”查看引擎建议。详细入口见 完整说明。

面板大小与位置

拖动标题栏移动，双击恢复默认位置和 100% 大小。拖动边缘或四角整体缩放，文字、图标与按钮同步变化；A− / A+ 每次调整 10%。位置和比例自动保存，小屏幕下正文可滚动。

操作变化

“反侦查辅助（操作变化）”控制选子前后的随机短暂停顿和点击位置变化。主面板可随时切换，设置保存后从下一步生效。

后台与暂停

自动行棋支持切换标签页、窗口覆盖和最小化。运行期间保持浏览器、棋局页面和网络连接；页面冻结、电脑休眠或浏览器关闭会中断处理，恢复后核对最新局面。

先点“暂停自动”或右上角暂停图标，再点独立的“确认暂停”。“继续运行”、Esc 或 8 秒未确认会收起确认条。

等待落子确认

落点发送后，面板显示“等待网站确认落子”，确认后继续。网页反馈延迟、短暂同步或读取超时会继续等待。换局、回放、身份变化、判错和终局会显示具体状态；等待期间也可使用两步操作暂停。

连接恢复

更新扩展后刷新棋盘，等待新面板就绪。页面提示“插件已更新，请重新连接”时，可点击浏览器工具栏的扩展按钮恢复面板，再重新开启自动行棋。
