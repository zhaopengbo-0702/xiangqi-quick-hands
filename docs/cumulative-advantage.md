# 平均优势的归一化积分

自 v2.8.0 起，主面板常驻显示“平均优势”。先对本局已记录的同一条 PCHIP 评估曲线做带符号积分，再除以首末记录手数跨度，得到范围为 $`[-1,1]`$ 的归一化平均评估。本页给出原始积分与归一化的完整运算关系；记录、视角和节点斜率规则见[本局评估走势](evaluation-history.md)。

## 输入与积分区间

设共有 $`n`$ 个记录点，按实际单方步手数递增排列：

```math
(t_i,v_i),\qquad i=0,\ldots,n-1.
```

$`v_i`$ 与图中点的有符号评分完全相同，参与对局时正值有利于自己、负值有利于对方。这里使用有符号评分，不取绝对值 $`q`$。普通评估沿用六位评分；非零杀棋点沿用图中的 $`+1`$ 或 $`-1`$，`mate = 0` 不生成数值点。没有可确认的我方身份时，沿用图表的统一分析方向。

令 $`F(t)`$ 为连接这些点的 PCHIP 曲线。对 $`n\ge2`$，先定义原始积分和手数跨度：

```math
\begin{aligned}
A&=\int_{t_0}^{t_{n-1}}F(t)\,\mathrm{d}t,\\
L&=t_{n-1}-t_0>0.
\end{aligned}
```

面板的平均优势为：

```math
M=\frac{A}{L}
=\frac{1}{t_{n-1}-t_0}
\int_{t_0}^{t_{n-1}}F(t)\,\mathrm{d}t.
```

积分只覆盖首个到末个真实记录点之间的插值曲线。中间没有独立计算的手数不额外生成记录点，也不向首末点之外外推。无点、只有一个点或跨度为零时，平均值没有定义，面板显示“平均优势 -”。单点对应的原始积分虽然为零，也不将平均优势显示为零。

## 同一条 Hermite 曲线

每段定义：

```math
\begin{aligned}
h_i&=t_{i+1}-t_i>0,\\
u&=\frac{t-t_i}{h_i},\qquad0\le u\le1.
\end{aligned}
```

$`d_i`$ 是 PCHIP 在节点 $`t_i`$ 的导数，按[走势文档中的保形斜率规则](evaluation-history.md#内部节点的一阶导数)计算。积分直接使用该组导数，与屏幕曲线的数学定义一致。

四个 Hermite 基函数为：

```math
\begin{aligned}
H_{00}(u)&=2u^3-3u^2+1,\\
H_{10}(u)&=u^3-2u^2+u,\\
H_{01}(u)&=-2u^3+3u^2,\\
H_{11}(u)&=u^3-u^2.
\end{aligned}
```

第 $`i`$ 段的评估为：

```math
\begin{aligned}
F_i(t)={}&H_{00}(u)v_i+H_{10}(u)h_id_i\\
&+H_{01}(u)v_{i+1}+H_{11}(u)h_id_{i+1}.
\end{aligned}
```

## 完整原函数

取四个在 $`u=0`$ 时均为零的原函数：

```math
\begin{aligned}
J_{00}(u)&=\frac{u^4}{2}-u^3+u,\\
J_{10}(u)&=\frac{u^4}{4}-\frac{2u^3}{3}+\frac{u^2}{2},\\
J_{01}(u)&=-\frac{u^4}{2}+u^3,\\
J_{11}(u)&=\frac{u^4}{4}-\frac{u^3}{3}.
\end{aligned}
```

它们满足 $`J_{ab}'(u)=H_{ab}(u)`$。第 $`i`$ 段从起点到任意位置的积分为：

```math
\begin{aligned}
\Phi_i(t)={}&h_i\bigl[J_{00}(u)v_i+J_{10}(u)h_id_i\\
&+J_{01}(u)v_{i+1}+J_{11}(u)h_id_{i+1}\bigr].
\end{aligned}
```

因为 $`\mathrm{d}t=h_i\,\mathrm{d}u`$，有：

```math
\Phi_i(t)=\int_{t_i}^{t}F_i(\tau)\,\mathrm{d}\tau.
```

## 每段精确积分与完整求和

四个基函数在单位区间上的积分依次为：

```math
\begin{aligned}
\int_0^1H_{00}(u)\,\mathrm{d}u&=\frac12,\\
\int_0^1H_{10}(u)\,\mathrm{d}u&=\frac1{12},\\
\int_0^1H_{01}(u)\,\mathrm{d}u&=\frac12,\\
\int_0^1H_{11}(u)\,\mathrm{d}u&=-\frac1{12}.
\end{aligned}
```

代入可得每段的精确积分：

```math
\begin{aligned}
A_i&=\int_{t_i}^{t_{i+1}}F_i(t)\,\mathrm{d}t\\
&=\frac{h_i(v_i+v_{i+1})}{2}
+\frac{h_i^2(d_i-d_{i+1})}{12}.
\end{aligned}
```

全部区间求和得到原始积分：

```math
A=\sum_{i=0}^{n-2}
\left[
\frac{h_i(v_i+v_{i+1})}{2}
+\frac{h_i^2(d_i-d_{i+1})}{12}
\right].
```

这是对 PCHIP 分段三次多项式的解析积分，不依赖图像像素或数值采样。SVG 绘图坐标的六位舍入不参与积分；同一手重算、开局点晚到或视角变化后，按更新后的完整记录重新构造曲线并计算。

再除以完整记录跨度，得到直接计算平均优势的公式：

```math
M=\frac{1}{t_{n-1}-t_0}
\sum_{i=0}^{n-2}
\left[
\frac{h_i(v_i+v_{i+1})}{2}
+\frac{h_i^2(d_i-d_{i+1})}{12}
\right].
```

面板最终将 $`M`$ 四舍五入到六位小数显示，正值带加号，零显示为 `0.000000`。舍入仅用于文字展示，计算平均值时使用完整精度的积分与跨度，不额外套用 tanh。

## 单位、范围与解读

横坐标的一手为一个单方步，原始积分 $`A`$ 的单位是“评分·手”，除以跨度 $`L`$ 后，$`M`$ 与评分使用同一无量纲尺度。这里按单方手数加权，不按实际经过的秒数加权。

## 范围保证的严格证明

以下证明在实数精确运算中进行，使用与代码一致的 PCHIP 内点与端点规则。假设 $`n\ge2`$，手数严格递增，所有输入点都满足 $`-1\le v_i\le1`$。因此 $`h_i>0`$、$`L>0`$，不存在零区间宽度。

### 定理一：实际斜率满足每段的保形条件

对任意 $`\delta_i\ne0`$ 的区间，定义归一化端点斜率：

```math
\alpha_i=\frac{d_i}{\delta_i},\qquad
\beta_i=\frac{d_{i+1}}{\delta_i}.
```

**结论为 $`0\le\alpha_i\le3`$、$`0\le\beta_i\le3`$。** 当 $`\delta_i=0`$ 时，两端导数均为零。

**内部节点证明。** 在内部节点 $`j`$，若 $`\delta_{j-1}\delta_j\le0`$，规则直接给出 $`d_j=0`$，对任一相邻非零割线的比值都为零。

若 $`\delta_{j-1}\delta_j>0`$，令：

```math
\begin{aligned}
a&=h_{j-1}>0,\qquad b=h_j>0,\\
w_1&=2b+a,\qquad w_2=b+2a.
\end{aligned}
```

调和平均公式为：

```math
d_j=\frac{w_1+w_2}
{w_1/\delta_{j-1}+w_2/\delta_j}.
```

两条割线同号，所以两个比值均严格为正，并且：

```math
\begin{aligned}
0\lt\frac{d_j}{\delta_{j-1}}
&=\frac{w_1+w_2}
{w_1+w_2\delta_{j-1}/\delta_j}\\
&\lt\frac{w_1+w_2}{w_1}
=\frac{3(a+b)}{a+2b}\lt3,\\
0\lt\frac{d_j}{\delta_j}
&=\frac{w_1+w_2}
{w_1\delta_j/\delta_{j-1}+w_2}\\
&\lt\frac{w_1+w_2}{w_2}
=\frac{3(a+b)}{2a+b}\lt3.
\end{aligned}
```

最后两个严格上界使用了 $`a,b>0`$。这同时证明内部节点对左右相邻区间均满足要求，而不要求手数等间隔。

**端点证明。** 左端点的原始候选斜率为：

```math
e=\frac{(2h_0+h_1)\delta_0-h_0\delta_1}{h_0+h_1}.
```

若 $`\delta_0=0`$，符号校正规则使最终 $`d_0=0`$。若 $`\delta_0\ne0`$，候选与 $`\delta_0`$ 异号时同样取零。其余情况下 $`e/\delta_0\ge0`$。

当 $`\delta_1/\delta_0\ge0`$ 时：

```math
0\le\frac{e}{\delta_0}
=\frac{2h_0+h_1}{h_0+h_1}
-\frac{h_0}{h_0+h_1}\frac{\delta_1}{\delta_0}
\le\frac{2h_0+h_1}{h_0+h_1}\lt2.
```

当 $`\delta_1/\delta_0\lt0`$ 时，规则将与割线同号但绝对值超过 $`3|\delta_0|`$ 的候选改为 $`3\delta_0`$，因而最终仍有 $`0\le d_0/\delta_0\le3`$。右端点规则使用反向排列的相邻间距与割线，推理完全相同。只有两个点时，两端斜率都等于唯一割线斜率，比值为 $`1`$。

最后，若某段 $`\delta_i=0`$，它所接的内部节点均触发乘积非正分支，端点也由上述零割线规则取零。因此 $`d_i=d_{i+1}=0`$。定理一得证。

### 定理二：每段单调且不超出相邻点范围

先考虑 $`\delta_i\ne0`$。令 $`\Delta_i=v_{i+1}-v_i`$，将该段写为：

```math
F_i(t)=v_i+\Delta_i p(u),\qquad
p(u)=H_{01}(u)+\alpha_iH_{10}(u)+\beta_iH_{11}(u).
```

由基函数直接得到 $`p(0)=0`$、$`p(1)=1`$。其导数为：

```math
\begin{aligned}
D(u;\alpha,\beta)=p'(u)
={}&6u(1-u)\\
&+\alpha(3u^2-4u+1)\\
&+\beta(3u^2-2u).
\end{aligned}
```

对固定 $`u\in[0,1]`$，$`D`$ 是 $`\alpha,\beta`$ 的仿射函数。在正方形 $`[0,3]^2`$ 的四角：

```math
\begin{aligned}
D(u;0,0)&=6u(1-u)\ge0,\\
D(u;3,0)&=3(1-u)^2\ge0,\\
D(u;0,3)&=3u^2\ge0,\\
D(u;3,3)&=3(2u-1)^2\ge0.
\end{aligned}
```

取 $`r=\alpha/3`$、$`s=\beta/3`$。由定理一有 $`r,s\in[0,1]`$，并且下式可直接展开验证：

```math
\begin{aligned}
D(u;\alpha,\beta)={}&(1-r)(1-s)D(u;0,0)\\
&+r(1-s)D(u;3,0)\\
&+(1-r)sD(u;0,3)\\
&+rsD(u;3,3).
\end{aligned}
```

四个权重均非负、和为一，因此 $`p'(u)\ge0`$。结合端点可得 $`0\le p(u)\le1`$。若 $`\Delta_i>0`$，$`F_i`$ 随手数非减；若 $`\Delta_i\lt0`$，$`F_i`$ 非增，两种情况都得到：

```math
\min(v_i,v_{i+1})\le F_i(t)\le\max(v_i,v_{i+1}).
```

若 $`\delta_i=0`$，由定理一知两端导数均为零，而 $`v_i=v_{i+1}`$。代入 Hermite 式并使用 $`H_{00}+H_{01}=1`$，得到 $`F_i(t)\equiv v_i`$。故零割线区间也不越界。定理二得证。

### 定理三：平均优势位于样点评分范围内

定义所有记录点的最小值与最大值：

```math
m_{\min}=\min_i v_i,\qquad m_{\max}=\max_i v_i.
```

由定理二，每一段以及整条曲线都满足：

```math
-1\le m_{\min}\le F(t)\le m_{\max}\le1.
```

对正长度区间积分，积分的保序性给出：

```math
m_{\min}L\le A\le m_{\max}L.
```

除以严格为正的 $`L`$，得到更强的界：

```math
-1\le m_{\min}\le M\le m_{\max}\le1.
```

因此 $`M\in[-1,1]`$，这个结论来自实际斜率规则与积分，不依赖程序最后的裁剪。若全部记录都是普通评分、没有杀棋端点，则所有 $`|v_i|\le0.999999`$，还可得到 $`|M|\le0.999999`$；包含杀棋点时使用 $`[-1,1]`$ 的统一界。

### 定理四：恒定值、符号反转与手数比例变换

**恒定值不变。** 所有样点均为 $`c`$ 时，所有割线与节点导数都为零。由定理二的零割线情形，整条曲线恒为 $`c`$，所以 $`A=cL`$、$`M=c`$。

**符号反转。** 将所有 $`v_i`$ 取反后，割线与候选端点斜率取反。内点乘积的符号、端点分支和绝对值比较不变，故所有 $`d_i`$ 也取反。Hermite 式对值与导数是线性的，因此 $`F`$、$`A`$、$`M`$ 同时取反，视角翻转不会改变平均优势的绝对值。

**手数平移与正比例缩放不变。** 把每个手数改为 $`\widetilde t_i=at_i+b`$，其中 $`a>0`$。此时 $`\widetilde h_i=ah_i`$、$`\widetilde\delta_i=\delta_i/a`$。加权调和平均和端点公式直接给出 $`\widetilde d_i=d_i/a`$，所有分支条件不变。局部变量 $`u`$ 及乘积 $`h_id_i`$ 不变，所以：

```math
\begin{aligned}
\widetilde F(at+b)&=F(t),\\
\widetilde A&=aA,\qquad\widetilde L=aL,\\
\widetilde M&=\frac{aA}{aL}=M.
\end{aligned}
```

这严格说明相同形状的曲线仅延长或缩短记录手数时，平均优势不会因积分区间变长而累加放大。

### 零跨度与浮点实现的区别

无点时没有积分区间；单点时 $`L=0`$，虽然退化区间积分为零，但 $`A/L=0/0`$ 没有定义。代码因此显示“平均优势 -”，不将未定义的平均值伪装成零。

上述定理是精确实数结论。实际 JavaScript 使用有限精度浮点数，代码在计算 $`A/L`$ 后限制到 $`[-1,1]`$，用于吸收末位舍入造成的微小越界；这一限制在精确数学中是冗余的，并非有界性的证明。最终 `toFixed(6)` 只处理文字展示，可能让不同的末位数值显示相同，不改变积分公式。

有界也不意味着无限延长记录时平均值必定收敛。若优势方向持续改变，且后续正负区间交替占据主导，平均值可以继续波动；本指标保证每个有效有限区间上的结果有界。

## 计算示例与解读

由于保形曲线始终满足 $`|F(t)|\le1`$，原始积分有如下跨度上界：

```math
\begin{aligned}
|A|&\le\int_{t_0}^{t_{n-1}}|F(t)|\,\mathrm{d}t\\
&\le t_{n-1}-t_0.
\end{aligned}
```

因此平均优势始终有界：

```math
|M|=\frac{|A|}{L}\le1,
\qquad -1\le M\le1.
```

持续保持同一评估 $`c`$ 时，任意正跨度都有：

```math
F(t)=c\quad\Longrightarrow\quad A=cL,\qquad M=c.
```

例如整个 20 手区间持续为 $`+0.5`$：

```math
A=20\times0.5=+10,\qquad M=\frac{10}{20}=+0.5.
```

再如，前 20 手区间的平均评估为 $`+0.5`$，后 10 手区间的平均评估为 $`-0.8`$：

```math
\begin{aligned}
A&=20\times0.5+10\times(-0.8)=+2,\\
M&=\frac{2}{30}\approx+0.066667.
\end{aligned}
```

此时最后一个局面的当前评估仍可为 $`-0.8`$。平均优势回答记录区间内哪一方平均占优，当前评估回答眼下局面哪一方占优。它是曲线平均值，不是胜率。进入时机和采样区间仍会影响含义，比较不同对局时应同时查看首末记录手数。

原始积分在长期持续正优势下可以随跨度增大，长期正负优势也可能抵消；它不必然趋向无穷。平均优势通过除以跨度保持有界，例如持续 $`+0.5`$ 时始终为 $`+0.5`$。

暂停、收起面板和重连引擎保留本局记录，也保留对应平均值；新局清空记录和平均值。视角整体反转时 $`v_i`$、$`d_i`$ 和 $`F(t)`$ 同时取反，因此 $`A`$ 与 $`M`$ 都取相反数。
