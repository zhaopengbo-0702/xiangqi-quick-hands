# 评估的各次转换与插值函数（自 v2.6.1 起）

本文给出从引擎评分到面板分数的完整数学过程。面板显示最终分数，中间尺度用于解释和复算；杀棋类型直接显示“杀棋 N”，采用独立分支。

## 输入与评分单位

当引擎结果为 `score.type = "cp"` 时，`score.value` 就是公式中的 $`\mathrm{cp}`$。例如 `score = {type: "cp", value: 22}` 对应 $`\mathrm{cp}=22`$。cp 是 centipawn，中文常称“百分兵分”，是引擎表达局势优劣的评分单位；$`100\ \mathrm{cp}`$ 对应旧版面板的 $`1.00`$。它综合子力、位置与搜索结果，表示局势评价而非胜率或实际兵数差。

评分沿用本次搜索开始时的行棋方视角，正值有利，负值不利。`score.type = "mate"` 时直接显示“杀棋 N”；有效普通评分缺失时显示“评估 -”。

## 引擎怎样产生百分兵分

整个过程分为三层：NNUE 评估搜索到的局面，搜索比较双方后续走法并回传内部值 $`v`$，引擎再将 $`v`$ 换算为对外报告的 $`\mathrm{cp}`$。

随插件打包的上游固定为 [`official-pikafish/Pikafish` 提交 `6a59ee2f7b105bff64d9efc2692591107787e2b1`](https://github.com/official-pikafish/Pikafish/tree/6a59ee2f7b105bff64d9efc2692591107787e2b1)，以下公式对应这份源码。

### NNUE 静态评估

[`src/evaluate.cpp`](https://github.com/official-pikafish/Pikafish/blob/6a59ee2f7b105bff64d9efc2692591107787e2b1/src/evaluate.cpp#L42) 调用 `network.evaluate(...)`，取得 `psqt` 与 `positional`。令 $`p`$ 和 $`s`$ 分别表示两项输出，$`o`$ 表示搜索传入的 `optimism`，$`M_{\mathrm{eval}}`$ 表示 `pos.major_material()`，$`r`$ 表示 `pos.rule60_count()`，则静态评估依次计算为：

```math
\begin{aligned}
(p,s)&=\mathrm{NNUE}(\text{局面},\text{累加器},\text{缓存}),\\
n_0&=p+s,\qquad c=|p-s|,\\
o_1&=o+\mathrm{trunc}\!\left(\frac{oc}{467}\right),\\
n_1&=n_0-\mathrm{trunc}\!\left(\frac{n_0c}{11698}\right),\\
v_0&=n_1+\mathrm{trunc}\!\left(\frac{n_1M_{\mathrm{eval}}+13371o_1}{36220}\right),\\
v_{\mathrm{leaf}}&=v_0-\mathrm{trunc}\!\left(\frac{v_0r}{244}\right).
\end{aligned}
```

这里 $`\mathrm{trunc}`$ 对应源码整数除法，向零截断。随后源码将普通静态评估限制在杀棋值范围之外。$`p`$、$`s`$ 来自 NNUE 网络及其训练权重，规则计数修正使长期无进展局面的评价衰减。静态评估子力量 $`M_{\mathrm{eval}}`$ 与下文对外换算使用的 $`M`$ 分别定义。

### 搜索回传

引擎使用 Negamax / Alpha-Beta、迭代加深和选择性搜索，比较我方着法及对方回应，在叶节点或静态搜索中调用评估，再向根节点回传 $`v`$。相关代码见 [`src/search.cpp` 的搜索回传](https://github.com/official-pikafish/Pikafish/blob/6a59ee2f7b105bff64d9efc2692591107787e2b1/src/search.cpp#L1301) 和 [静态评估调用](https://github.com/official-pikafish/Pikafish/blob/6a59ee2f7b105bff64d9efc2692591107787e2b1/src/search.cpp#L1837)。最终内部评分由实际网络权重、搜索分支、深度与可用时间共同决定。

### 内部值到百分兵分

[`src/score.cpp`](https://github.com/official-pikafish/Pikafish/blob/6a59ee2f7b105bff64d9efc2692591107787e2b1/src/score.cpp#L29) 将普通内部值交给 `UCIEngine::to_cp(v, pos)`，决定性值交给杀棋分支。普通分数的换算来自 [`src/uci.cpp` 的局面参数](https://github.com/official-pikafish/Pikafish/blob/6a59ee2f7b105bff64d9efc2692591107787e2b1/src/uci.cpp#L535) 和 [`to_cp`](https://github.com/official-pikafish/Pikafish/blob/6a59ee2f7b105bff64d9efc2692591107787e2b1/src/uci.cpp#L578)：

```math
\begin{aligned}
M&=10N_R+5N_N+5N_C+3N_B+2N_A+N_P,\\
m&=\frac{\mathrm{clamp}(M,17,110)}{65},\\
a(m)&=220.59891365m^3-810.35730430m^2\\
&\quad+928.68185198m+79.83955423,\\
\mathrm{cp}&=\mathrm{round}\!\left(\frac{100v}{a(m)}\right).
\end{aligned}
```

$`N_R,N_N,N_C,N_B,N_A,N_P`$ 分别为全盘双方合计的车、马、炮、象、士、兵数量。$`M`$ 统计这些棋子的加权总量；$`\mathrm{clamp}`$ 将其限制在 $`[17,110]`$。$`\mathrm{round}`$ 对应源码的 `std::round`，半整数向远离零方向取整。此处子力数量确定评分尺度 $`a(m)`$，实际局势值 $`v`$ 来自前述 NNUE 与搜索。

例如，当 $`M=65`$、$`v=418`$ 时：

```math
\begin{aligned}
m&=1,\\
a(1)&=418.76301556,\\
\mathrm{cp}&=\mathrm{round}\!\left(\frac{100\times418}{418.76301556}\right)=100.
\end{aligned}
```

这套对外尺度与引擎拟合的 WDL 参数有关。后续 tanh 和 PCHIP 负责面板显示，搜索仍使用引擎原始评分。

## 完整转换链

给定有限普通评分 $`\mathrm{cp}`$，依次完成单位换算、解析变换、插值和显示：

```math
\mathrm{cp}
\xrightarrow{\div100}x
\xrightarrow{\tanh(1.5x)}u
\xrightarrow{\mathrm{sgn}(u)P(|u|)}y
\xrightarrow{\text{钳制、六位舍入}}s.
```

各步定义为：

```math
\begin{aligned}
x&=\frac{\mathrm{cp}}{100},\\
u&=\tanh(1.5x)=\tanh(0.015\mathrm{cp}),\\
b&=|u|,\qquad \mathrm{sgn}(0)=0,\\
y&=\mathrm{sgn}(u)P(b),\\
\widehat y&=\mathrm{clamp}(y,-0.999999,0.999999),\\
s&=R_6(\widehat y),\qquad q=|s|.
\end{aligned}
```

其中 $`x`$ 是 v2.6.0 以前的面板尺度，$`u`$ 是 v2.6.0 未舍入、未钳制的分数，$`y`$ 是插值结果。$`R_6`$ 表示与面板 `toFixed(6)` 相同的六位小数舍入，零统一显示为 $`0.000000`$，$`q`$ 用于最终分档。双曲正切函数为：

```math
\tanh z=\frac{e^{2z}-1}{e^{2z}+1}.
```

实际计算使用双曲正切函数求值。系数 $`1.5`$ 调节尺度，输入 $`\mathrm{cp}`$ 的范围为有限实数。**单位换算和 tanh 是前置转换，第三步 $`u\to y`$ 才使用插值**，插值输入取完整精度的 $`u`$。

tanh 的数学值域是 $`(-1,1)`$；极端输入可能在浮点计算中饱和为 $`\pm1`$。补全插值端点及最终钳制使普通分数始终按六位显示在 $`[-0.999999,0.999999]`$ 内。浮点饱和、舍入和钳制可使不同的大评分显示相同，插值的精度由原始引擎评分与这些显示规则共同决定。

## 六个精确节点

令 $`X_i`$ 为输入绝对值，$`Y_i`$ 为输出绝对值。使用下表的精确十进制字面值作为节点，计算时直接读取这些常量：

| 节点 $`i`$ | $`X_i`$ | $`Y_i`$ |
| --- | --- | --- |
| $`0`$ | $`0`$ | $`0`$ |
| $`1`$ | $`0.635148952387`$ | $`0.5`$ |
| $`2`$ | $`0.978026114739`$ | $`0.7`$ |
| $`3`$ | $`0.999753210848`$ | $`0.9`$ |
| $`4`$ | $`0.999999969540`$ | $`0.99`$ |
| $`5`$ | $`1`$ | $`1`$ |

插值满足节点条件，并通过奇对称延拓到负半轴：

```math
P(X_i)=Y_i\quad(i=0,\ldots,5),\qquad F(-b)=-P(b).
```

端点 $`(0,0)`$ 与 $`(1,1)`$ 补全正半轴定义域 $`[0,1]`$。

## 节点斜率

区间宽度与割线斜率定义为：

```math
h_i=X_{i+1}-X_i,\qquad
\delta_i=\frac{Y_{i+1}-Y_i}{h_i},\qquad i=0,\ldots,4.
```

节点一阶导数记为 $`d_i`$。内部节点 $`i=1,\ldots,4`$ 使用 Fritsch–Butland 加权调和平均：

```math
\begin{aligned}
w_1&=2h_i+h_{i-1},\\
w_2&=h_i+2h_{i-1},\\
d_i&=
\begin{cases}
0,&\delta_{i-1}\delta_i\le0,\\
\displaystyle\frac{w_1+w_2}{w_1/\delta_{i-1}+w_2/\delta_i},
&\delta_{i-1}\delta_i>0.
\end{cases}
\end{aligned}
```

左右端点先作单边估计：

```math
\begin{aligned}
d_0^{\ast}&=\frac{(2h_0+h_1)\delta_0-h_0\delta_1}{h_0+h_1},\\
d_5^{\ast}&=\frac{(2h_4+h_3)\delta_4-h_4\delta_3}{h_4+h_3}.
\end{aligned}
```

端点限制规则与 SciPy `PchipInterpolator` 相同。定义端点修正函数：

```math
E(d,\delta,\eta)=
\begin{cases}
0,&\mathrm{sgn}(d)\ne\mathrm{sgn}(\delta),\\
3\delta,&\mathrm{sgn}(\delta)\ne\mathrm{sgn}(\eta)
\ \text{且}\ |d|>3|\delta|,\\
d,&\text{其余情况}.
\end{cases}
```

于是 $`d_0=E(d_0^{\ast},\delta_0,\delta_1)`$，$`d_5=E(d_5^{\ast},\delta_4,\delta_3)`$。本组割线均为正，端点取各自单边估计。参考斜率如下：

| 节点 $`i`$ | $`d_i`$ |
| --- | --- |
| $`0`$ | $`0.9196449521966364`$ |
| $`1`$ | $`0.6603012392333599`$ |
| $`2`$ | $`1.4797679604891136`$ |
| $`3`$ | $`26.01724018542384`$ |
| $`4`$ | $`1091.6262809772932`$ |
| $`5`$ | $`328339.88482224976`$ |

靠近 $`1`$ 的输入区间很窄，相应节点导数较大。

## 五个区间的插值函数

对于 $`b\in[X_i,X_{i+1}]`$，定义局部参数 $`t_i=(b-X_i)/h_i`$。三次 Hermite 基函数为：

```math
\begin{aligned}
H_{00}(t)&=2t^3-3t^2+1,&H_{10}(t)&=t^3-2t^2+t,\\
H_{01}(t)&=-2t^3+3t^2,&H_{11}(t)&=t^3-t^2.
\end{aligned}
```

每个区间上的函数为：

```math
\begin{aligned}
P_i(b)={}&H_{00}(t_i)Y_i+H_{10}(t_i)h_id_i\\
&+H_{01}(t_i)Y_{i+1}+H_{11}(t_i)h_id_{i+1}.
\end{aligned}
```

等价局部多项式及系数为：

```math
\begin{aligned}
P_i(b)&=A_it_i^3+B_it_i^2+C_it_i+D_i,\\
A_i&=2Y_i-2Y_{i+1}+h_i(d_i+d_{i+1}),\\
B_i&=-3Y_i+3Y_{i+1}-h_i(2d_i+d_{i+1}),\\
C_i&=h_id_i,\qquad D_i=Y_i.
\end{aligned}
```

五个局部参数分别为：

| $`i`$ | $`b`$ 所在区间 | $`t_i`$ |
| --- | --- | --- |
| $`0`$ | $`[0,0.635148952387]`$ | $`\displaystyle\frac{b}{0.635148952387}`$ |
| $`1`$ | $`[0.635148952387,0.978026114739]`$ | $`\displaystyle\frac{b-0.635148952387}{0.978026114739-0.635148952387}`$ |
| $`2`$ | $`[0.978026114739,0.999753210848]`$ | $`\displaystyle\frac{b-0.978026114739}{0.999753210848-0.978026114739}`$ |
| $`3`$ | $`[0.999753210848,0.999999969540]`$ | $`\displaystyle\frac{b-0.999753210848}{0.999999969540-0.999753210848}`$ |
| $`4`$ | $`[0.999999969540,1]`$ | $`\displaystyle\frac{b-0.999999969540}{1-0.999999969540}`$ |

系数保留双精度参考输出，运行时按节点和斜率规则动态生成：

| $`i`$ | $`A_i`$ | $`B_i`$ | $`C_i`$ | $`D_i`$ |
| --- | --- | --- | --- | --- |
| $`0`$ | $`0.003501168314592769`$ | $`-0.08761269627027911`$ | $`0.5841115279556863`$ | $`0`$ |
| $`1`$ | $`0.3337808544377575`$ | $`-0.36018306964360114`$ | $`0.22640221520584358`$ | $`0.5`$ |
| $`2`$ | $`0.19743013869620432`$ | $`-0.029581199392770027`$ | $`0.03215106069656577`$ | $`0.7`$ |
| $`3`$ | $`0.09578825340447801`$ | $`-0.012208233562085181`$ | $`0.006419980157607156`$ | $`0.9`$ |
| $`4`$ | $`-0.009965516182746442`$ | $`0.01993226524626417`$ | $`0.00003325093648228132`$ | $`0.99`$ |

逐段展开为：

```math
\begin{aligned}
P_0(b)={}&0.003501168314592769t_0^3-0.08761269627027911t_0^2\\
&+0.5841115279556863t_0,\\
P_1(b)={}&0.3337808544377575t_1^3-0.36018306964360114t_1^2\\
&+0.22640221520584358t_1+0.5,\\
P_2(b)={}&0.19743013869620432t_2^3-0.029581199392770027t_2^2\\
&+0.03215106069656577t_2+0.7,\\
P_3(b)={}&0.09578825340447801t_3^3-0.012208233562085181t_3^2\\
&+0.006419980157607156t_3+0.9,\\
P_4(b)={}&-0.009965516182746442t_4^3+0.01993226524626417t_4^2\\
&+0.00003325093648228132t_4+0.99.
\end{aligned}
```

求值使用 Horner 形式：

```math
P_i(b)=\bigl((A_it_i+B_i)t_i+C_i\bigr)t_i+D_i.
```

相邻段在公共节点上的函数值和一阶导数相同，整条曲线为 $`C^1`$ 连续，二阶导数按段定义。局部参数 $`t_i`$ 使每段在 $`[0,1]`$ 内求值，适合处理最后几个较窄的输入区间。

## 从系统数值到面板值的完整复算

给定 `score = {type: "cp", value: 22}`，首先计算：

```math
\begin{aligned}
\mathrm{cp}&=22,\\
x&=\frac{22}{100}=0.22,\\
u&=\tanh(1.5\times0.22)=\tanh(0.33)\\
&\approx0.31852077690277081,\\
b&=|u|=0.31852077690277081.
\end{aligned}
```

因为 $`b\in[0,0.635148952387]`$，取第 $`0`$ 段：

```math
t_0=\frac{b}{0.635148952387}\approx0.50148988785341531.
```

将 $`t_0`$ 代入该段多项式：

```math
\begin{aligned}
P_0(b)={}&0.003501168314592769t_0^3\\
&-0.08761269627027911t_0^2+0.5841115279556863t_0\\
\approx{}&0.00044156996967228306\\
&-0.02203390163921604+0.2929260246483842\\
\approx{}&0.27133369297884041.
\end{aligned}
```

恢复符号并执行显示规则：

```math
\begin{aligned}
y&=\mathrm{sgn}(u)P_0(|u|)=+0.27133369297884041,\\
\widehat y&=\mathrm{clamp}(y,-0.999999,0.999999)=y,\\
s&=R_6(\widehat y)=+0.271334,\\
q&=|s|=0.271334<0.5.
\end{aligned}
```

面板显示 **“评估 +0.271334”** 和 **“均势”**。输入 $`\mathrm{cp}=-22`$ 时，$`u`$、$`y`$ 和 $`s`$ 按奇对称取反，得到“评估 -0.271334”和“均势”。计算全程保留 $`u`$ 的浮点精度，最后一步统一舍入。

## 为什么选择 PCHIP

线性插值通过节点且保持单调，节点处通常带有斜率折角。自然三次样条追求二阶连续并将端点二阶导数设为零，在本组高度不均匀的节点上会出现过冲和局部回折。PCHIP 通过受限的一阶斜率构建分段三次 Hermite 曲线，准确通过节点、保持单调、避免区间过冲，同时实现 $`C^1`$ 连续，因此用于这里的评分重标度。

运行时使用上述节点和斜率规则，以 JavaScript 完成计算。SciPy `PchipInterpolator` 作为开发期数值参考，用于核对节点、斜率、系数和区间输出；本组节点的密集取样比较也用于检查曲线形状。

## 六位显示与局势分档

令 $`q=|s|`$ 为最终六位显示分数的绝对值，四个分界产生五个区间：

| 最终六位绝对值 $`q`$ | 正分 / 负分分档 |
| --- | --- |
| $`q<0.5`$ | 均势 |
| $`0.5\le q<0.7`$ | 稍优 / 稍劣 |
| $`0.7\le q<0.9`$ | 明显优势 / 明显劣势 |
| $`0.9\le q<0.99`$ | 大幅优势 / 大幅劣势 |
| $`q\ge0.99`$ | 接近胜势 / 接近败势 |

从 v2.6.1 起，显示值舍入到边界即归入该边界起始的区间，使分档文字与分数一致。普通评分使用此表，杀棋报告沿用独立显示。
